# Computer Logic Design Projects

A collection of digital logic design projects developed using **VHDL**. The projects demonstrate the design, implementation, and simulation of combinational and sequential digital circuits.

## Skills & Concepts

* Digital logic and Boolean algebra
* Logic gate design
* Multiplexers and hierarchical circuit design
* Arithmetic circuits and adders
* Sequential logic and registers
* VHDL
* Component-based and modular design
* Digital circuit simulation and waveform analysis
* Quartus design and simulation tools

## Project Structure

### `01_Logic_gates`

Contains VHDL implementations of multi-input NAND gates along with their corresponding waveform files.

* `.vhd` — VHDL source files containing the circuit implementations.
* `.vwf` — waveform files used to define and visualize simulation inputs and outputs.

### `02_Multiplexers`

Contains VHDL implementations of multiplexers of different sizes, demonstrating modular and hierarchical circuit design.

The `.vwf` files contain the corresponding simulation waveforms used to test the circuit behavior.

### `03_Adders`

Contains VHDL implementations of arithmetic circuits, including full adders and multi-bit adders.

The projects demonstrate how smaller components can be combined to create larger arithmetic circuits. The `.vwf` files document the simulation inputs and expected circuit behavior.

### `04_Registers`

Contains VHDL implementations of sequential logic circuits, including a D flip-flop and registers of different sizes.

The accompanying `.vwf` files contain the simulation waveforms used to observe and verify the behavior of the sequential circuits.

## File Types

| Extension | Description                                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| `.vhd`    | VHDL source code used to describe the digital circuits                                                               |
| `.vwf`    | Quartus Vector Waveform Files containing simulation inputs, outputs, timing information, and waveform configurations |

The waveform files are included as **simulation artifacts** to provide evidence of circuit testing and to document the behavior of the corresponding VHDL designs.

## Overview

These projects demonstrate practical experience with **digital circuit design, VHDL, modular design, hierarchical components, simulation, and verification** across both combinational and sequential logic.
